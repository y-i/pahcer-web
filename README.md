# pahcer-web

[pahcer](https://github.com/terry-u16/pahcer)の機能をWebから使うためのCLIツールです。(pahcer v0.3.1の機能に対応してます)

以下の機能があります。

- pahcerを用いたテストの実行
  - pahcerの各種オプションに加え、実行終了時の通知も可能
- pahcerの初期設定
- テスト実行結果の確認・ビジュアライザでの確認
- 実行結果間でのスコアの比較・分析
- テスト実行やビジュアライザなどの設定

WSL環境でのみ確認しました。

# インストール方法

事前にRust環境及びpahcerのインストールが必要です。

```shell
cargo install pahcer-web
```

# 基本的な使い方

1. `pahcer`を利用するディレクトリで`pahcer init`を実行(省略可)
2. `pahcer-web ui`を実行し、`http://localhost:10432/`を開く
3. 1.を省略していた場合、セットアップ用画面が表示されるので、このタイミングで初期化設定を行う![](/images/setup.png)
4. テスト実行タブからコメント等を設定しテストを実行する![](/images/menu.png)
5. 実行履歴タブで実行結果を確認

# その他の使い方

## pahcer-web ui

`pahcer-web run -d /tmp/ahc9999`のようにオプションとしてディレクトリを渡すことができます。渡されたディレクトリを基準として動作するようになります。`-p`オプションでUIのポートも変更可能です。

## pahcer-web run

`pahcer v0.3.1`の`pahcer run`と同じオプションが利用可能です。この実行結果は`pahcer-web`側にも記録されます。
こちらはキャンセルできません。

## 実行履歴タブ

実行履歴の行をクリックするとビジュアライザを開くことが出来ます。(設定タブでビジュアライザをダウンロードしていない場合は設定が必要)
不要な結果は削除できます。

各実行履歴の詳細ボタンを押して各seedの結果を表示している場合は、各seedの結果を直接開くことも出来ます。

ビジュアライザを開いた状態はそれぞれURLが分かれているので別のタブなどでも開くことが可能です。

## スコア分析タブ

実行結果間でのスコアの比較・分析ができます。
スコアの形式は右上のボタンで変更できますが、永続的な変更には設定での変更が必要です。

## 設定タブ

各種設定が可能で、左側が全体での設定、右側がプロジェクト毎の設定用です。
全体の設定は`XDG_CONFIG_HOME`で指定したディレクトリの`pahcer-web`以下に保存されます。
プロジェクト毎の設定は`pahcer`を動かすディレクトリの`.pahcer-web`以下に保存されます。

設定可能な項目は以下のとおりです。

- テスト実行
  - デフォルトのオプション
  - 完了時の通知
- ビジュアライザ
  - URL
  - 左右の表示位置
  - 上下のスクロール位置
  - デフォルトのseedと拡大率
- スコア分析
  - デフォルトのスコアのタイプ
  - 入力1行目のパラメータ名

# 開発用

## 開発

次を実行します。

```bash
pnpm turbo run dev
```

フロントエンドがポート5173で立ち上がり、`pahcer-web`のサーバがポート10432からリクエストをフロントエンドにプロキシします。それぞれの変更は自動反映されます。

別ディレクトリの`pahcer`を使いつつ開発をしたい場合は、`cli/package.json`の`dev`のスクリプトに引数を付けて行うのが簡単だと思います。

## ビルド

```bash
pnpm turbo run build
```

`frontend`のビルド結果が`cli/frontend-assets`にコピーされます。`pahcer-web`のサーバはポート10432で起動し、これをホストします。
